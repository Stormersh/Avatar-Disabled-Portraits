# Avatar - Disabled Portraits
Disables the portraits from the Avatar - Four Nations Restored mod (CK2). Does not disable portraits for canon characters (Zuko, Iroh, Kyoshi and so on). Maintains Avatar backgrounds as well.

Requirements:

- Avatar - Four Nations Restored (https://github.com/Rystic/ATLA-restored)

----
## Instructions

- Allows you to play without the portraits added by the main mod

- If you want to play with anime portraits, select
  - Avatar - Anime Portraits
  - Anime Portraits: https://steamcommunity.com/sharedfiles/filedetails/?id=756755380
